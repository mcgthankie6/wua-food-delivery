# WUA Cafeteria Express

## Project Overview
WUA Cafeteria Express is a food ordering and delivery application for university students, staff, and faculty.

## Functional Requirements
1. Users can browse menus from different campus cafeterias.
2. Users can place food orders.
3. Users can track their deliveries in real time.
4. Users can make cashless payments.

## Project Users
- Students
- University staff
- Faculty members
- Cafeteria operators
- Delivery personnel
