Git and GitHub Reflection

1. Challenges Encountered
During the WUA Cafeteria Express project, our team used Git and GitHub to organise project files, manage branches and collaborate on the development of the application. We experienced challenges coordinating the work and ensuring that the required project files and documentation were completed.

2. Merge Conflicts
Our team did not encounter or resolve a merge conflict during this project. However, we learned that Git provides tools for managing changes made by different team members and that conflicts should be reviewed carefully before changes are merged.

3. Teamwork and Collaboration
The project demonstrated the importance of dividing tasks, communicating progress and checking one another's work. We used feature branches and pull requests to organise changes before merging them into the develop branch. We also learned that every team member needs to contribute consistently to complete a group project successfully.

4. Future Use of Git
In future projects, we will use Git and GitHub to track changes, maintain organised branches, review code and collaborate more effectively. We will also aim to communicate more consistently, test our changes before merging and ensure that submission documentation is complete.
